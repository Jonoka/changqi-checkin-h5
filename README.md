# 长岐村漫游打卡 H5

**v1.3 · 仓库文档基线 · 2026-09-21**

面向“印象芦苞”微信公众号的轻量照片打卡活动：菜单进入 → 页面内扫码 → 上传现场照片 → 完成全部地点 → 现场领取 → 标记领取人数。

仓库：`Jonoka/changqi-checkin-h5`，默认分支 `main`，保持私有。本次初始化写入开发依据、Agent 约定、环境变量样例和视觉参考说明；**不含应用代码，尚不能启动；A0–A6 均未开始，也未接入真实公众号、MySQL 或服务器。**

五张高分辨率 PNG 原图尚未写入 GitHub：现有连接没有可直接接收本地大附件的上传入口，容器也无法连接 GitHub 推送。原图已保留为配套的“长岐村漫游打卡_待入库视觉原图.zip”；具体文件与校验信息见 [视觉说明](assets/reference/README.md) 和 [原图清单](assets/reference/manifest.json)。不要把“文档已入库”理解为“原图或应用已经完成”。

## 开发边界

预算几千元、目标交付窗口 2–3 天；按最小可用闭环做，不按人工团队分工或人日排期。只服务一个公众号、一场活动；无后台、无库存、无员工账号、无复杂防刷。仅照片打卡。领取状态由游客自行确认或持领取码者确认派发，两条路径共用一个状态，不重复计数。

空仓库默认使用 Vue 3 + Vite、Node.js + Express、MySQL、Nginx。A0 核对实际环境并锁定兼容版本；已有可运行模板优先复用，不为本项目另换技术栈。公众号和正式域名权限未核验时继续本地开发，但不得宣称真实微信流程已通过。

## 仓库初始化

已核对用户指定的 `Jonoka/changqi-checkin-h5`：初始化前无分支，是空的私有仓库，连接具备写入权限。材料提交到默认分支 `main`；不修改可见性、不选择开源许可证、不自动部署，也不创建无必要的 PR。

继续开发时以实际仓库和工作区为准，先读取现有文件，保留本地修改及环境文件，不以初始化模板重新覆盖。

远端已有初始化提交；本仓库目前没有 `package.json`、业务源代码、锁文件或数据库脚本。具体工程骨架、安装命令、依赖和数据库由 A0 实现并实际检查。**仓库初始化不等于 A0 通过；应用构建、MySQL、微信真机和部署均仍未验证。**
